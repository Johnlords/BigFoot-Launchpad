# BIGFOOT - Degen-First Multi-Chain Meme Coin Launchpad

The first launchpad built for traders, by traders. 👣

## Overview

BIGFOOT is a trader-first multi-chain meme coin launchpad on Solana and BNB Chain (BSC).

We return 70% of all platform fees directly to traders as cashback — creating a fairer and more rewarding ecosystem for degens.

### Key Features
- 70% cashback to traders on every trade
- Faster bonding curve (~$43k MC graduation)
- Advanced anti-bot & anti-sybil protections
- Live Auto Trading Bot — [app.bigfoothunterai.tech](https://app.bigfoothunterai.tech)
- Beautiful misty forest-themed UI
- Viral referral system

## Tech Stack
- Frontend: Next.js + React + Tailwind CSS + Shadcn
- Solana**: Anchor Framework (Rust)
- BSC**: Solidity Smart Contracts
- Backend: FastAPI + MongoDB (simulation layer)
